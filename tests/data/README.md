# Test data

`yale_blendshapes.npz`: MediaPipe Face Landmarker 0.10.35 blendshape scores (52 per photo, `NAMES` order, rounded
to 4 decimals) computed from the 165 photos of the Yale Face Database (15 people x 11 conditions: centerlight,
glasses, happy, leftlight, noglasses, normal, rightlight, sad, sleepy, surprised, wink). Only these numbers are
stored, no image.

Acknowledgement: the photos come from the Yale Face Database (P. N. Belhumeur, J. P. Hespanha, D. J. Kriegman,
"Eigenfaces vs. Fisherfaces: Recognition Using Class Specific Linear Projection", IEEE TPAMI 19(7), 1997).
